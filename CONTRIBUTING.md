# Contributing

Start with the README and AGENTS.md. Use a focused branch and a pull request that states the design sections, implemented behavior, exact tests, and remaining limitations. Do not mark a prototype as a production safety guarantee.

Changes to contracts require positive and negative shared fixtures and regenerated Rust/TypeScript outputs. Run all checks in the README. Security boundaries need an independent human review before being relied on. Green CI is necessary, not sufficient.

Use a real Developer Certificate of Origin sign-off when you are entitled to make it. Do not add someone else's sign-off, invent an email identity, or represent automated code as a completed human review. The initial automated implementation still requires the maintainer's review and any required sign-off before merge.

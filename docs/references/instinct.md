# Instinct reference: a personal assistant rather than a command form

Reviewed 2026-10-05, following the user's suggestion. Source: [Instinct's official homepage](https://instinct.com/), as publicly indexed on this date. Direct retrieval was blocked by a robots-check error. No logged-in product, call, message, integration or underlying model was tested.

## What the public description supports

Instinct presents itself as an assistant that understands ongoing work and personal importance, connected to applications/devices such as email, messaging and screen/audio/location context. Its described entry points are ordinary text and phone conversation. Examples extend to personal errands and neglected conversations. These are the service's product claims, not independently measured reliability or evidence of its internal implementation.

## Tada decisions informed by that reference

Keep conversation as the primary interface. The user delegates the work of identifying relevant context and sources as well as execution. Follow-up must remain related to the earlier work rather than reopening a task form. Prioritize useful outcomes in work and everyday life, not an expanding inventory of tools or developer-only milestones.

Existing communication surfaces and voice are valuable later entry points into the same assistant; they are not a reason to create separate agents with separate context. The current terminal is an incremental entry point, not the final interaction design. Current situation awareness and connected sources remain essential to understanding “this” without a selected file.

Proactive assistance must stay within the user's approved remit. An example of proactive outreach on another product's website does not authorize Tada to monitor continuously, transmit private context, create recurring jobs or make new commitments without the appropriate user instruction. Permitted context should reduce user preparation, not justify indiscriminate collection.

Tada retains local execution/state ownership and its current authorization, cancellation and result-verification boundaries. The homepage does not establish Instinct's hosting architecture, privacy guarantees, model training methods, subscriptions, API compatibility or availability for this user; none is inferred or copied. No brand, UI asset, source or private protocol is imported.

## Effect on the current implementation

The ongoing natural-conversation preview is the first concrete integration, not a redefinition of the goal as a read-only file chatbot. It must preserve self-directed discovery and same-conversation revision while growing toward current-screen/app context, connected/public sources, authorized actions and verified results. Live-model observations and unresolved failures belong in the PR; the sixteen broader product acceptance cases stay unrun until actually evaluated.

# 같은 대화에서 문서를 만들고 수정하기

사용자는 비서를 맡겼는데 상담 상대 같은 문구와 대화 화면만 제공됐다고 지적했다. 이 변경은 실제로 남는 결과물 하나를 같은 대화에 연결한다. 문구 개선을 비서 완성으로 취급하지 않는다.

## 사용 흐름

“새 프로젝트를 시작할 때 확인할 항목을 체크리스트 문서로 만들어줘”처럼 부탁하면 모델이 일반 문서 도구를 선택해 문서를 준비하고 본문을 작성한다. 확정된 답변에는 제목·버전·내려받기 버튼이 붙는다. Markdown 또는 텍스트 파일을 받을 수 있다. “아까 문서를 한 문장으로 줄여줘” 같은 후속 요청에서는 저장된 문서를 찾아 읽고 새 버전으로 작성한다. 원본은 보존한다. 특정 문구를 실행 스크립트에 매칭하지 않는다.

기본 대화에 `list_documents`, `read_document`, `prepare_document`를 등록했다. 모델이 제목과 형식, 수정할 문서를 지정하고 최종 답변을 본문으로 작성한다. 도구의 준비 결과는 저장 완료를 뜻하지 않는다. 자료에 의존한 사실은 기존 인용 검사·자료 재확인을 통과해야 하며, 최종 답변과 문서 메타데이터가 같은 암호화 트랜잭션에서 저장돼야 내려받을 수 있다. 내려받는 파일에는 인용한 자료의 목록도 포함한다.

## 보존과 경계

문서는 기존 연락 DB의 암호화된 답변에 추가 메타데이터로 저장한다. 별도 평문 파일 저장소나 새 DB 전환은 없다. 원본 본문 해시를 저장하고 읽을 때 확인한다. 버전은 호스트가 부여하고 직전 버전을 연결한다. 목록·조회·모델 문맥에 원본 ID와 이전 버전 ID를 남겨 같은 제목의 문서도 계보로 구별한다. 이전 버전을 바탕으로 최신 버전을 조용히 덮어쓰지 않는다. 외부 공개·발송, 사용자의 임의 경로 파일 변경 권한은 생기지 않는다. 예약된 읽기 전용 재확인에는 문서 도구를 추가하지 않는다.

공급자의 구조화된 작성 거절은 대화 답변으로만 남기며 새 문서·새 버전으로 발행하지 않는다. 취소·기기 권한 폐기·중단·본문 생성 실패 뒤에는 준비만 된 문서를 완료 결과로 저장하지 않는다. 인증된 같은 소유자의 기기만 문서를 읽고 내려받을 수 있다. 브라우저에서는 모델의 HTML을 실행하지 않고 본문을 텍스트로 표시하며, 다운로드는 attachment와 no-store로 응답한다. 이름은 호스트가 생성하므로 모델의 제목을 경로나 HTTP 헤더로 사용하지 않는다.

문서 본문은 현재 4 KiB 이내의 짧은 문서다. 기존 14,000바이트 모델 문맥·64회 요청 한도를 늘리지 않는다. ChatGPT 문맥 크기는 실제 직렬화한 요청으로 측정해 내부 메시지와 공급자 continuation을 중복 계산하지 않는다. 도구 정의도 한도에 포함한다. 문서 조회는 메타데이터 한 줄과 본문 원문을 도구 데이터로 전달해 JSON 중첩 이스케이프를 피한다. 문서의 출처도 일반 자료 조회와 같은 인용 보정·최종 재검증을 거친다. 전체 대화·도구·본문이 한도를 넘으면 기존 중단 규칙이 적용된다. 확정된 문서 턴은 모델의 이어가기 문맥에서 제목·ID·버전의 짧은 영수증으로 바꾸고, 본문은 암호화된 답변에서 필요할 때 조회한다. 실제 관측·사용량·원래 요청·자료 증거는 보존한다. ChatGPT의 해당 턴 continuation도 함께 제거해 변형된 문맥과 공급자 상태가 충돌하지 않게 한다. 문서 조회 결과의 중복 본문도 다음 턴에 계속 쌓지 않는다.

## 검증 범위

실제 SQLite·HTTP 저장/다운로드 경로로 생성, 재시작 후 조회와 수정, 원본 보존, 다운로드 바이트 해시, 미인증/폐기된 기기 차단, 취소 후 늦은 결과 폐기, 출처 변경 시 발행 거절, 최대 본문 길이의 수정, 구독 프로토콜 문맥 복원을 검사한다. 구독 HTTP 프로토콜로 최대 길이 문서를 저장하고 재시작한 뒤 목록·조회·수정을 거치는 테스트는 각 크기 측정값이 실제 전송 요청과 같은지도 확인한다. 따옴표가 많은 본문, 동일한 제목의 서로 다른 문서 계보, 수정 시 누락 인용 보정과 출처 변경, 준비 후 공급자 거절도 회귀 검사한다. 모델은 합성이므로 이는 자연어 이해나 실제 계정의 업무 수행 품질 증명이 아니다.

실제 ChatGPT 계정 로그인·추론 검증은 사용자 연결을 기다린다. Google 연결이 설정된 연락 호스트는 최근 메일·기본 캘린더를 읽을 수 있지만, 일반적인 컴퓨터 작업, 메일 발송·일정 편집·회신 감지, 외부 문서 편집, 긴 문서와 장기 기억, 설치 프로그램과 전체 제품 인수 검증은 남아 있다. 이 기능은 문서 결과를 전달하는 한 경로이며 출시 가능한 비서라는 선언이 아니다.
